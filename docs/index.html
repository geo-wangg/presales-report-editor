如何编辑一份报告

  1. 导入平台生成的售前报告 HTML，工具会自动进入编辑模式。
  2. 点击文案直接修改。选中文字后，用底部的文字格式工具设置加粗或颜色。
  3. 点击数值或图表打开数据面板。占比类图表可同时填写各项数据，合计 100% 后一次应用；也可以手动选择按比例调整。
  4. 点击报告上方的“预览报告”查看效果；“撤销 / 重做”可以回退或恢复本次修改。
  5. 点击“另存为 HTML”，浏览器会下载新报告。下次可直接打开，或重新导入本工具继续编辑。

当前支持同一套模板，品牌、竞品、主题和平台数量可不同。分析文案与上游业务诊断不会自动重写；改变模板结构、替换图片暂不支持。

当前报告还有未保存的修改

导入另一份报告会结束当前编辑。可以先取消并另存当前报告，或直接切换。
